# CampusAI 🎓🤖

### One Intelligent Platform for a Smarter Campus

CampusAI is an AI-powered campus assistance platform designed to connect students and college administration through a single, centralized system.

It provides students with quick access to campus information such as notices, events, timetable, FAQs and complaint tracking, while administrators can manage campus data, complaints, FAQs and view analytics through an admin dashboard.

Students can ask questions related to:

- Events

- Complaints
